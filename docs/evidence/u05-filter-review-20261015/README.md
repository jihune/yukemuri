# 데스크톱 왼쪽 필터 검토(U05, 2026-10-15)

기록: 2026-10-15T10:55Z. 사용자 의견(10-15 08:4xZ) ‘사이트 좌측에 있는 필터가 상당히 현재 별로같다’에 대한 검토다. 대상은 U05 4번(PR #95)의 데스크톱 왼쪽 패널이다. 이 폴더의 캡처는 로컬 사이트(main `43f2b4f` + PR #108 빌드)를 실제 Chromium으로 연 것이다. 숙소 사진과 지도 타일은 빈 그림으로 바꿨다(숙소 사진 없음). 목업은 브라우저에서 CSS·DOM만 바꾼 그림이고, 사이트 코드는 바꾸지 않았다(`mock-*.css`, `mock-*.js`). 목업 C의 켜짐 상태는 그림으로 그린 것이다.

## 지금 화면에서 보이는 문제

캡처: `current-1280-top.png`, `current-1440-top.png`, `current-1280-panel-bottom.png`.

1. **패널이 너무 길다.** 패널 열은 220px이고, 안의 내용은 1,337px이다. 1280×800 화면에서는 463px(35%)만 보이고, 1440×900에서는 585px만 보인다. 그래서 평점 조건(평점 출처·최소 평점·최소 리뷰 수)을 보려면 패널 안에서 두세 화면을 내려야 한다.
2. **같은 조건이 두 번 나온다.** 위 칩 막대에는 ‘내 기준’과 탕 조건 6개(천연온천·노천탕·객실 온천·전세탕·니고리유·카케나가시)가 있다. 바로 아래 패널에도 같은 조건이 스위치로 또 있다. 넓은 화면에서 같은 일을 하는 조작이 둘이다.
3. **좁아서 줄이 깨진다.**
   - 15개 중 4개 이름이 두 줄이 된다(니고리유 · 탁한 온천, 카케나가시 · 흘려보내는 온천, 공용 대욕장 노천탕, 내 검증 기준 상자).
   - ‘내 검증 기준’ 상자는 ‘Trip.com / 9.0+ · 리뷰 / 50+’처럼 네 줄로 끊긴다.
   - 평점 출처 선택 상자의 글자(‘Trip.com · 10점 만점’)가 잘린다.
4. **스위치가 설정 화면처럼 보인다.** 조건 15개가 모두 회색 스위치다. 그래서 화면이 무겁고, 조건을 고른다기보다 설정을 켜고 끄는 느낌을 준다. 수는 스위치 옆에 작은 회색 글자로만 있다.
5. **세부 조건이 핵심 조건과 같은 무게다.** 공용 대욕장 노천탕, 전세·가족 노천탕, 객실 실내 온천탕, 객실 노천 온천탕 4개는 세부 조건이다. 그런데 카드의 6칸과 같은 핵심 조건과 같은 줄·같은 무게로 섞여 있다.

## 고칠 방향(시안)

### A. 넓은 화면도 칩 막대 하나로(왼쪽 패널 없음)

캡처: `a-1280-top.png`, `a-1440-top.png`.

- 왼쪽 열을 없앤다. 칩 막대 끝에 ‘필터 더 보기(조건 수)’를 두고, 누르면 휴대폰과 같은 필터 시트가 열린다. 데스크톱에서는 오른쪽이나 위에서 내려오는 판으로 연다.
- 목록과 지도가 244px을 더 쓴다. 목록 열이 1280px에서 474px → 568px, 1440px에서 554px → 644px이 된다(목업에서 잰 값).
- 조작이 한 곳뿐이라 같은 조건이 두 번 나오는 문제가 사라진다. 휴대폰과 데스크톱이 같은 모양이 된다.
- 단점: 세부 조건과 평점 조건을 바꾸려면 한 번 더 눌러야 한다. 지금 켜진 세부 조건을 칩 막대에 칩으로 보여 줘야 한다.

### B. 왼쪽 패널을 짧은 체크 목록으로

캡처: `b-1280-top.png`, `b-1440-top.png`.

- 열을 260px로 넓히고, 스위치 대신 카드의 ✓ 칸과 같은 체크 상자를 쓴다.
- 이름은 한 줄로 쓴다(니고리유·카케나가시·전세탕). 설명은 ‘?’ 안에 둔다.
- 세부 조건 4개는 ‘세부 조건 더 보기’로 접는다.
- 넓은 화면에서는 위 칩 막대를 숨겨 같은 조건이 두 번 나오지 않게 한다. 내용 높이는 1,337px에서 1,092px이 된다(목업 값, 접은 4개 포함).
- 단점: 패널은 여전히 길다. 평점 조건은 아래에 남는다.

### C. 두 단계 패널: 자주 쓰는 조건 칸 + 나머지는 묶음별로 접기

캡처: `c-1280-top.png`, `c-1440-top.png`.

- 패널 맨 위에 ‘내 기준’과 탕 6칸을 2열 칩 칸으로 둔다. 카드의 6칸과 같은 이름과 순서다.
- 그 아래 온천수 세부, 공용·전세탕 세부, 객실탕 세부, 숙소 유형, 평점을 묶음별로 접는다(처음에는 닫힘).
- 위 칩 막대는 넓은 화면에서 숨긴다.
- 내용 높이는 577px이다(목업 값). 1280×800에서도 한 화면에 들어간다.
- 단점: 세부 조건이 한 번 더 눌러야 보인다. 묶음을 열면 다시 길어진다.

## 권장

C를 권한다. 카드의 6칸과 같은 말·같은 순서로 고르게 되고, 한 화면에 들어오고, 중복이 사라진다. 왼쪽 열을 아예 없애도 괜찮다면 A가 가장 단순하다.
