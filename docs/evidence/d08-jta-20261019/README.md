## 한계

- 우리 기록에는 전화번호가 없어서 전화는 대조하지 않았다. 이름과 주소만 대조한다.
- 이 측정은 스냅숏 검색 문맥에서 잘라 낸 주소를 쓴다. 실제 카드는 스냅숏을 만들 때 저장된 숙소 기록을 읽어 정하므로 배포 뒤 수가 조금 다를 수 있다. 배포 뒤 공개 스냅숏의 `jta` 수를 다시 세어 이 표와 비교한다.
- 목록에 옛 이름으로 남은 숙소는 주소가 같아도 잇지 않았다. 이어지지 않은 1,081행에는 우리 목록에 없는 숙소와 이렇게 이름이 달라진 숙소가 섞여 있다. 둘을 나눠 세지는 않았다.
