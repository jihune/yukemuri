### 자동화 UA 규칙(PR 1)

키가 맞는 요청은 먼저 통과한다. 그 밖의 Worker 요청에서 아래면 403이다. D1과 속도 제한 카운터에 닿지 않는다.

1. `User-Agent`가 없거나 비었다.
2. `Mozilla/`나 `Opera/`로 시작하지 않는다(브라우저가 아닌 도구의 기본 UA).
3. 알려진 수집기 표지가 있다: `bot/`·`bot;`·`bot)`·`bot-`로 끝나는 이름, `crawl`, `spider`, `slurp`, `scrap`, `facebookexternalhit`, `meta-external`, `ChatGPT-User`, `Perplexity-User`, `Claude-User`, `anthropic-ai`, `cohere-ai`.

- `HeadlessChrome`은 막지 않는다. 이 레포의 브라우저 검사(Playwright)가 그 UA로 로컬 사이트의 `/api/*`를 부른다.
- 이름 끝 `bot`만 보는 이유: 휴대폰 모델명(예: `CUBOT`) 뒤에는 공백이 오므로 오탐을 줄인다.
- 켜고 끄기: 생성된 `wrangler.json`의 `vars.REJECT_AUTOMATED_AGENTS="1"`일 때만 동작한다. Miniflare로 Worker를 직접 띄우는 기존 검사 12개는 이 값을 주지 않아 지금처럼 동작한다. 배포 설정 검사와 배포 smoke가 값과 실제 거절을 확인하므로 빠지면 드러난다.

## 상세 API 실패 응답(U05 상세 화면용)

브라우저가 `/api/hotels/<id>`나 `/api/hotel-comparison`에서 받는 응답과, `lib/api-client.ts`의 `apiJson`이 던지는 `ApiError`다(main `fbc5389` + 이 PR 기준).

| 경우 | 상태 | 본문 | `ApiError` |
|---|---|---|---|
| 숙소 없음 | 404 | JSON `{"error":"숙소를 찾을 수 없습니다."}` | `status: 404`, `retryable: false` |
| 앱 안의 D1 오류 | 503 | JSON `{"error":"숙소 상세를 불러오지 못했습니다."}`(비교는 그 경로의 문구) | `status: 503`, `retryable: false` |
| IP별 속도 제한(이 PR) | 429 | JSON `{"error":"요청이 너무 많습니다. 1분쯤 뒤에 다시 시도해 주세요."}`, `Retry-After: 60`, `Cache-Control: no-store` | `status: 429`, `retryable: false` |
| 자동화 도구 거절(이 PR, 브라우저는 받지 않음) | 403 | JSON `{"error":"브라우저가 아닌 자동화 도구의 요청은 받지 않습니다."}` | `status: 403`, `retryable: false` |
| Worker 하루 한도 초과(1027) | 429로 보임(추정) | Cloudflare HTML 오류 화면, JSON 아님 | `status` 없음, `retryable: true`(GET은 350ms 뒤 한 번 다시 보냄) |
| Worker 예외(1101) | 500 | Cloudflare HTML 오류 화면 | 위와 같음 |
| CPU·메모리 초과(1102) | 503 | Cloudflare HTML 오류 화면 | 위와 같음 |
| 연결 실패 | 없음 | 없음 | `status` 없음, `retryable: true`, 문구 ‘연결이 원활하지 않습니다…’ |

- 1027의 상태 코드는 문서에서 확인하지 못했다. `error-1027` 문서 주소는 404였다(12:52Z). billing 문서는 무료 한도를 넘은 `run_worker_first` 요청이 429를 받는다고 쓴다. 1101은 500, 1102는 503이다(문서 `error-1101`·`error-1102`의 관련 오류 목록).
- 화면이 구분할 수 있는 것: `status`가 없으면(HTML 오류·연결 실패) Worker나 네트워크 문제다. 429·503도 잠시 뒤 다시 될 수 있다. 404만 숙소가 없다는 뜻이다. 그래서 스냅숏 카드로 대신 보여 줄 조건은 ‘404가 아님’이 가장 단순하다.
