### 재현

| 관찰 | 재현 결과 | 원인 |
|---|---|---|
| 필터 패널의 아래쪽 체크박스가 푸터에 가려진다 | 보고한 형태로는 재현되지 않았다. 패널은 900px 초과 폭에서 높이가 화면 높이−40px이고 안에서 스크롤된다. 패널 안을 끝까지 내리면 마지막 조작 요소(‘최소 리뷰 수’)가 세 폭 모두 보이고 눌린다. 패널 아래 경계 밖의 체크박스 중심점은 `elementFromPoint`가 푸터를 돌려준다. 패널이 잘라 낸 부분이라 그렇다. U01의 관찰은 이것을 가림으로 읽은 것으로 보인다(추정). | 해당 없음 |
| 위 관찰과 같은 화면의 실제 문제 | 목록 끝에서 패널 위쪽이 화면 밖으로 밀려난다. 패널 위 끝은 1280px에서 −64px, 비교 막대가 있으면 −125px이다. 제목 옆 ‘초기화’ 버튼은 −41px(막대 있음 −102px)에 있다. 막대가 있으면 ‘내 검증 기준’ 체크박스도 밖에 있다. 패널 안 스크롤로는 볼 수 없고 페이지를 다시 올려야 한다. 1024·1440px도 같다. | 고정(sticky) 패널은 목록 끝에서 작업 영역 아래 끝에 멈춘다. 그 위치는 화면 아래에서 푸터 64px(막대가 있으면 125px)과 작업 영역 아래 여백 40px만큼 위다. 패널 높이(화면−40px)가 그 공간보다 커서 위로 밀렸다. |
| 지도 미리보기가 Leaflet 출처 표시를 가린다 | 재현했다. 1280·1440px에서 ‘Leaflet’ 링크, 1024px에서 ‘OpenStreetMap’ 링크의 중심점이 미리보기 카드에 가려졌다. 출처 표시 높이는 38px(두 줄)이었다. | 두 가지가 겹쳤다. ① 출처 표시의 `max-width:90%`가 내용 크기로 줄어드는 모서리 상자를 기준으로 계산되어 두 줄로 접혔다. ② 미리보기 카드의 `bottom:55px` 기준이 지도가 아니라 지도 아래 안내 줄까지 포함한 `.map-sticky`였다. 안내 줄이 두 줄이 되는 1024px에서 카드는 지도 바닥에서 9px 위까지 내려왔다. |

①만 고친 중간 확인에서 1280·1440px은 해결됐다. 1024px은 두 링크가 모두 가려진 채 남아 ②도 고쳤다.

### 수정

- `app/globals.css`: 900px 초과 폭에서 필터 패널 최대 높이를 `100dvh − 124px`, 비교 막대가 있으면 `100dvh − 185px`로 줄였다. 위 20px, 작업 영역 아래 여백 40px, 푸터 높이 64px(막대가 있으면 125px)의 합이다. 대가로 페이지 중간에서도 패널 보이는 높이가 84px(막대가 있으면 145px) 줄고, 나머지는 패널 안 스크롤로 본다.
- `app/globals.css`: 출처 표시의 최대 너비를 지도 모서리 상자(`.leaflet-control-container .leaflet-right`)의 90%로 옮겼다. 출처 표시는 한 줄(19px)이 된다.
- `components/hotel-explorer.tsx`·`app/globals.css`: 지도와 미리보기 카드를 `.map-frame` 하나로 묶었다. 카드는 어느 폭에서나 지도 바닥에서 55px 위에 놓인다. 휴대폰 지도 화면의 `.view-map .map-preview{bottom:100px}`는 지웠다. 360/390px에서 이 값은 안내 줄 높이를 빼면 지도 바닥에서 55px이었으므로 위치가 같다(수정 전후 모두 카드 424–514px, 지도 49–569px).
- 지도 타일과 출처 표시 문구는 바꾸지 않았다.

### 검사

- 새 검사 `scripts/check-u03-desktop-browser.mjs`: 폭마다 4개, 모두 12개. 목록 끝에서 패널 전체가 화면 안·푸터 위에 있고 첫 조작 요소(‘초기화’)와 마지막 조작 요소를 누를 수 있다(비교 막대 없음·있음). 미리보기와 출처 표시가 겹치지 않고 두 출처 링크를 누를 수 있다. 미리보기가 지도 안에 있다.
- 수정본: 12개 통과(2026-10-11T05:04Z). [근거](evidence/ui-u03-desktop-20261011.json).
- 대조: 같은 서버에서 수정 전 `app/globals.css`·`components/hotel-explorer.tsx`로 되돌리면 9개가 실패했다. 패널 위 끝 −48~−125px, 출처 표시 38px·링크 가림이다. ‘미리보기가 지도 안에 있음’ 3개는 보조 단언이라 양쪽 모두 통과한다. [근거](evidence/ui-u03-desktop-before-20261011.json).

### 미확인

- 외부 지도 타일이 실제로 그려진 상태의 겹침. 출처 표시와 카드 위치는 타일과 관계없이 정해진다.
- 1024px 미만 901px 이상의 폭, 높이 700px 미만 창. 패널 최대 높이가 더 작아질 뿐 계산식은 같다.
- 푸터 높이는 64px 한 줄을 가정한다. 푸터 문구가 두 줄로 바뀌면 다시 계산해야 한다.
- 스크린리더, 실제 기기.
