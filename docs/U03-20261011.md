## B. 비교 화면 차이 강조

브랜치: `claude/u03-comparison-diff`. 시작 기준: main `11f03e7`(PR #22 병합).

### 목표

비교 시트에서 후보 2~4곳의 값이 다른 항목을 빨리 찾게 한다. 미확인 정보를 같음이나 다름으로 추정하지 않는다.

### 대상 항목

현재 비교표의 행을 그대로 쓴다. 행을 더하거나 빼지 않는다.

| 행 | 차이 판단 | 비교하는 값 |
|---|---|---|
| Trip.com · 10점 | 한다 | 화면에 보이는 점수(소수 첫째 자리). 리뷰 수와 확인일은 비교하지 않는다. |
| 자란넷 · 5점 | 한다 | 위와 같다. |
| 내 검증 기준 | 한다 | 충족·미충족. Trip.com 평점이 없으면 미확인이다. |
| 시설 13행(온천수·공용·객실 목욕 시설, 자란 하이클래스) | 한다 | 있음·없음, 그리고 있음이면 객실 적용 범위(일부 객실·전 객실) |
| Google Maps · 5점 | 하지 않는다 | 비교표에 점수가 없고 지도 연결만 있다. |
| 주소, 온천수 안내 | 하지 않는다 | 숙소마다 다른 설명 문장이라 차이 표시가 도움이 되지 않는다. 참고 항목으로 둔다. |

가격대는 현재 비교표에 없다. 실시간 요금 조회를 종료했으므로 이 작업에서 더하지 않는다.

평점은 같은 행 안에서만 비교한다. 한 행은 한 출처와 한 척도다(`providerRating`이 출처와 척도를 함께 고른다). Trip.com 10점과 자란 5점을 서로 비교하거나 환산하지 않는다.

### ‘다름’·‘같음’·‘판단 보류’

후보 하나의 값은 미확인일 수 있다. 미확인은 다음 경우다. 평점이 없다. 시설 값이 `null`(화면의 ‘확인 필요’)이다. 기록을 찾지 못했다(‘기록 없음’).
객실 시설이 있음인데 적용 범위가 기록되지 않았으면(화면의 ‘있음 · 객실 타입 확인’), 있음은 확인됐고 범위는 미확인이다.

- 다름: 두 후보의 확인된 값이 서로 다르다. 있음과 없음, 또는 둘 다 있음이고 확인된 범위가 일부 객실과 전 객실로 다르다. 다른 후보에 미확인이 있어도 다름이다. 확인된 두 값만으로 판단했기 때문이다.
- 같음: 모든 후보의 값이 확인됐고 모두 같다.
- 판단 보류: 다름도 같음도 아니다. 확인된 값끼리는 같지만 미확인인 후보가 있다. 또는 범위 미확인 때문에 같은지 알 수 없다.

‘없음’은 확인된 값이다. 미확인과 섞지 않는다. ‘없음’과 ‘있음’은 다름이고, ‘없음’과 미확인은 판단 보류다.
후보가 1곳이면 차이를 표시하지 않는다.

### 표시

- 다름 행: 행 머리에 ‘다름’ 글자 표지를 붙인다. 행 배경을 옅게 칠하고 행 머리 왼쪽에 굵은 선을 둔다. 색과 선은 보조이고 글자 표지가 기준이다.
- 판단 보류 행: 행 머리에 ‘판단 보류 · 미확인 N곳’을 작은 글자로 쓴다.
- 같음 행: 표지를 붙이지 않는다.
- 도구 줄에 요약 문장을 둔다. ‘값이 다른 항목 N개 · 미확인으로 판단 보류 M개’.
- ‘다른 항목만 보기’ 전환 버튼을 둔다(`aria-pressed`). 켜면 다름 행만 남긴다. 같음·판단 보류·참고 항목은 숨긴다. 숨긴 수를 표 아래에 쓴다. 다름이 0개면 ‘확인된 값이 다른 항목이 없습니다’를 표에 쓴다. 미확인은 판단하지 않았다는 말을 붙인다.
- 전환 상태는 시트를 닫아도 페이지에 남는다. 후보가 1곳이 되면 버튼을 숨기고 모든 행을 보인다.

### 접근성

- 표지는 행 머리(`th scope="row"`) 안의 글자라서 스크린리더가 행 이름과 함께 읽는다. 아이콘은 `aria-hidden`이다.
- 전환 버튼은 키보드(Enter·Space)와 터치로 누른다. 누른 뒤 포커스는 버튼에 남는다. 상태 변화는 `aria-live` 문장(‘다른 항목 N개만 표시 중’ / ‘모든 항목 표시 중’)으로 알린다.
- U01의 시트 동작을 유지한다. 열면 닫기 버튼에 포커스가 간다. Tab은 시트 안에서 돈다. 후보 제거 뒤 다음 제거 버튼으로 포커스가 간다. Escape로 닫으면 연 버튼으로 돌아간다.
- 버튼 높이는 44px 이상이다.

- 판정 함수는 `lib/comparison-differences.ts`에 둔다. `scripts/check-comparison-differences.mjs`가 다름·같음·판단 보류, 없음과 미확인의 구분, 범위 미확인, 후보 1곳을 단언한다. `cloud-check.py`에 더한다.
- 실제 브라우저 검사 `scripts/check-u03-comparison-browser.mjs`: 360/390px 터치·키보드, 1280px 마우스·키보드. 후보 2곳, 4곳, 거의 모든 값이 미확인인 기록, 찾을 수 없는 ID.
- 대조: 판정 함수가 미확인을 다름으로 보면 단위 검사가 실패해야 한다. 수정 전 main에서는 브라우저 검사가 실패해야 한다.
