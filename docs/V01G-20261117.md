- V01-5. `.github/workflows/deploy.yml`의 `deploy`, `collect.yml`의 `collect`와 `snapshot`, `d1-setup.yml`의 `d1`, `rollback.yml`의 `rollback` job에 `if: github.ref == 'refs/heads/main'`을 넣었다(`snapshot`은 앞에 AND로). `lifecycle.yml`의 `apply`와 `collect.yml`의 `chain`은 이미 있었다. 줄은 각 job의 `steps:` 바로 위에 두었다. `check-daily-check.mjs` 31줄 정규식이 `collect:` 뒤에 `runs-on:`과 `timeout-minutes:`가 이어지기를 요구하고 `check-collect-workflow.mjs`도 `timeout-minutes: 26` 바로 뒤 `outputs:`를 요구해서, 줄을 그 사이가 아니라 `steps:` 바로 위에 두면 열린 PR #314가 고치는 `check-daily-check.mjs`를 고치지 않아도 된다.
