## 변경

- 비교에서 상세를 열 때 비교표를 유지한다. 상세의 닫기·Escape·뒤로 가기로 비교에 돌아온다.
- 상세를 열었던 같은 숙소명 버튼으로 포커스가 돌아온다. 비교표 스크롤 값도 유지한다.
- 후보 제거 시 인접 제거 버튼으로 포커스를 옮긴다. 마지막 후보 제거와 모두 비우기는 닫기 버튼으로 이동한다.
- 수집 현황에 빈 기록 안내를 추가했다. 비교·현황 표에 포커스 영역·방향키 처리·이동 안내를 추가했다.
- 새로고침 중에는 버튼 포커스를 유지하고 중복 요청을 막는다. 현황 조회 상태를 알린다.
- 수집 현황의 표와 도구 글자는 좁은 화면에서도 14px로 유지한다. 비교 닫기 버튼이 줄어들지 않게 했다.
