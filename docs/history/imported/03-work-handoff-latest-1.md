## 변경과 원문 대조

운영의 형식 오류 상세 8개·목록 3개를 모두 대조했다.
11개 모두 HTTP 200과 windows-31j 원문을 반환했다.

목록에서는 각각 30개·21개·14개를 읽었다.
과거 원문과 구체적인 예외 메시지가 없어 ValueError의 정확한 원인은 미확정이다.
현재 원문에서 파서 오류를 재현했다고 주장하지 않는다.

기존 `--diagnose-source`는 숙소 문서 수만 세고 유효 관측을 확인하지 않았다.
목록 주소도 상세 요청으로 취급했다.
진단 모드의 `--diagnostic-dir`은 작동하지 않았다.
일반 ValueError도 처리하지 않았다.
이 네 문제를 수정했다.
`parse_source_page`로 수집과 진단의 기존 ID·국가·빈 자료 검사를 공유한다.
문서 없음·ID 불일치·유효 관측 없음·빈 목록과 요청·본문 확인·해석 단계를 로그로 구분한다.
진단은 큐를 변경하지 않고 주소 이동을 따라가지 않는다.
예외의 원문 메시지나 비밀을 출력하지 않는다.
