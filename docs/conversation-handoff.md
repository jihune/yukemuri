## 확정한 방향

- 개인용 일본 온천 숙소 탐색이다. Trip.com 검색 사용성과 평점/리뷰, Jalan 객실·온천 자료를 함께 확인한다. 실시간 가격 비교는 종료했다.
- 기존 Sites 호스팅과 운영 D1을 유지한다. 전체 앱 개발 기준은 이 레포다(2026-10-11부터 public). 사용자 PC로 이관하지 않는다.
- Codex 웹과 Claude Code 웹은 같은 레포·PR·공통 지침을 사용한다. 서비스별 구독 변경과 작업 대화 기억에 의존하지 않는다.
- GitHub는 연결 도구·API·인증된 git을 우선한다. 클라우드 브라우저로 자동 전환하지 않는다. 이미 받은 같은 작업의 허가는 반복 요청하지 않는다.
- 자료 갱신은 기존 Python 예약이 맡는다. 매번 게시된 Sites 수집기를 받아 검사한다. 3시간 주기·순차 간격·robots·임대·재전송·실제 접근 제한을 유지한다.
- 일일 DB 백업과 임시 복원 검사는 기존 실행기에 추가했다. 자세한 운영 절차는 `db-backups.md`를 따른다.
- 출처 ID·원어명·주소·객실 적용 범위와 원래 점수 척도를 보존한다. 유사한 이름만으로 합치거나 404를 폐업으로 판단하지 않는다.
- Sites 연결이 없는 웹 환경에서는 코드·검사·검토·배포 인수인계를 완료한다. 스킬 문서만으로 배포 권한을 얻는다고 가정하지 않는다.

## 보존 범위와 한계

계정 ZIP의 분할 대화 형식을 지원하도록 가져오기 도구를 수정했다. native file ID·공유 첨부·Library 참조를 지원하고 잘못된 ID·덮어쓰기·Git 작업 폴더 출력·ZIP 경로 탈출을 검사한다.

Sites 원래 Git bundle과 D1 전체 SQL·배포/버전/런타임 메타데이터도 비공개 보존했다. SQL을 새 임시 SQLite에서 검사했고 운영 DB를 변경하지 않았다. 서비스가 제외한 49개 생성 빌드 산출물은 원래 소스로 재생성할 자료이며 Secret 값은 서비스에서 가렸다.
