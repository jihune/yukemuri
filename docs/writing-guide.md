# 문장·용어 규칙

조사·기록 시각: 2026-10-07T08:26:00Z / 한국시간 17:26.

## ASD-STE100 조사

공식 STEMG 자료는 ASD-STE100을 영어 기술 문서용 통제 언어로 설명한다. 공식 안내의 판본은 Issue 9, 2025-01-15이다. 작성 규칙과 승인 어휘 사전이 함께 사용된다. 짧은 문장, 한 문장에 한 주제, 능동형과 일관된 용어는 다른 글쓰기에도 적용할 수 있다.

이 프로젝트는 이 원칙을 한국어에 적용한다. 영어 승인 어휘와 영어 단어 수 제한을 한국어에 그대로 적용하지 않는다. ‘80% 준수’나 공식 인증을 주장하지 않는다. 간결한 문장이 사실 확인을 대신하지 않는다.

사용자가 언급한 Karpathy 게시물의 원문 링크는 찾았지만 검색 도구가 본문을 가져오지 못했다. 발언을 직접 인용하지 않는다. 개발 기준은 공식 자료에서 확인한 원칙을 따른다.

## 적용 규칙

1. 한 문장에 한 사실이나 지시를 쓴다. 긴 절차는 번호로 나눈다.
2. 주체와 동작을 쓴다. ‘처리가 진행됩니다’보다 ‘수집기가 페이지를 확인한다’로 쓴다.
3. 쉬운 말을 쓴다. ‘고도화·혁신·강력한·완벽한’처럼 결과를 설명하지 않는 말을 삭제한다.
4. 같은 개념에 같은 용어를 쓴다. 아래 용어표와 코드 식별자를 유지한다.
5. 조건과 한계를 보존한다. ‘일부 객실’, ‘API 미연결’, ‘확인 필요’를 생략하지 않는다.
6. 관측, 구현과 계획을 구분한다. HTTP 200, 작업 성공, 저장과 전체 수집 완료를 같은 뜻으로 쓰지 않는다.
7. 수치에는 측정 시각과 단위를 쓴다. 근거 없는 비율이나 ‘최신’이라는 표현을 쓰지 않는다.
8. 반복 설명·형식적 서론·상투적 결론을 삭제한다. 변경 이유와 검증 결과는 남긴다.

| 용어 | 뜻 |
|---|---|
| 숙소 기록 | 공급자별 항목. 같은 건물의 다른 출처 기록이 포함될 수 있음 |
| 관측 | 특정 출처에서 특정 시각에 읽은 정보 |
| 상세 완료 페이지 | 상세 수집 성공 페이지. 모든 시설의 확인을 뜻하지 않음 |
| 확인 필요 | 현재 근거로 판단할 수 없음 |
| 출처 대기 | 공급자 제한·오류 때문에 저장한 요청 보류 |
| 체크포인트 | 기록 시각의 상태. 이후 변경 가능 |

예: ‘전국 정보를 완벽하게 최신화했습니다’ 대신 ‘10월 7일 10:03 KST 예약은 16페이지를 처리하고 관측 86개를 저장했다. 미처리 페이지가 남아 있다’로 쓴다.

## 사용자 교정

사용자가 에이전트의 문장을 고치거나 거절하면 아래 표에 원문과 수정문을 한 줄로 추가한다. 문서·보고를 쓰기 전에 이 표를 읽는다. 이 표가 위 규칙보다 우선한다. 기록: 2026-10-10.

## 문서 갱신

기록 시각(UTC와 KST), 코드·배포 근거, 확인한 동작, 검사와 남은 작업을 쓴다. 운영 수치에는 측정 시각을 따로 쓴다. 후속 기록은 새 체크포인트를 추가하거나 별도 수정 시각을 남긴다. 확인하지 않은 과거 문서의 날짜를 새로 쓰지 않는다.
