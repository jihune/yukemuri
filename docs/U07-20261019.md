# U07 — 화면 보강(왼쪽 필터·도움말·이름 복사)

기록: 2026-10-17T17:0xZ, 네 번째 상위 세션. 상태: 시작 전(10-19T12:10Z 재개 뒤 새 하위 세션이 맡는다). 이 문서는 첫 brief이고, 맡은 세션이 설계·검사·결과를 이어 적는다. 앞선 화면 작업은 `U05-20261013.md`(2단계, 왼쪽 필터 C안 포함)에 있다.

## 사용자 원문(10-17T16:5xZ)

1. ‘왼쪽 필터 선택시 체크 표시가되면서 글자가 밀리면서 잘리는 현상 개선 필요.’
2. ‘왼쪽 필터 개별 옵션에 대한 도움말 툴팁도 있으면 좋겠음. 또는마우스오버 툴팁’
3. ‘번역 방식은 가급적 한국어가 없으면 영어이름도 괜찮다. … 그리고 원래 숙소 이름 일본어나 영어 복사하기 쉽게 클립보드 복사 원클릭 아이콘 추가해줘’

## 할 것

1. 왼쪽 필터(데스크톱 두 단계 패널과 휴대폰 시트)에서 옵션을 고르면 체크 표시가 생기며 글자가 밀려 잘린다. 체크 표시 자리를 처음부터 잡아 두는 방식 등으로, 고르기 전후에 글자 위치와 줄바꿈이 바뀌지 않게 한다.
2. 옵션마다 짧은 도움말을 둔다. 데스크톱은 마우스를 올리면 보이고, 휴대폰은 작은 도움말 단추를 누르면 보인다. 키보드 초점과 스크린리더(`aria-describedby` 등)로도 읽혀야 한다. 문구는 `lib/collection-status.ts`의 정의, 카드 표기와 같은 말을 쓴다.
3. 숙소 카드와 상세에서 원어(일본어) 이름과 영어 이름 옆에 한 번 누르면 복사되는 단추를 둔다. 복사되면 짧게 ‘복사됨’을 알린다. 클립보드를 쓸 수 없는 브라우저에서는 이름을 선택해 둔다.
4. 이름 표시 순서가 한국어 → 영어 → 원어인지 확인한다. 다르면 고친다. 자료를 늘리는 일은 D07이 맡는다.
5. 상위 세션 제안(사용자 확인 전, 넣을지는 맡은 세션이 판단하고 PR에 이유를 적는다): 숙소 설명 옆에 ‘Google 번역에서 보기’ 웹 링크를 둔다. `translate.google.com` 웹 페이지를 여는 링크라 API와 비용이 없고 휴대폰 브라우저에서도 열린다. LLM 번역은 쓰지 않는다(사용자 결정, `roadmap.md` 결정 기록).
