## 할 것

1. 왼쪽 필터(데스크톱 두 단계 패널과 휴대폰 시트)에서 옵션을 고르면 체크 표시가 생기며 글자가 밀려 잘린다. 체크 표시 자리를 처음부터 잡아 두는 방식 등으로, 고르기 전후에 글자 위치와 줄바꿈이 바뀌지 않게 한다.
2. 옵션마다 짧은 도움말을 둔다. 데스크톱은 마우스를 올리면 보이고, 휴대폰은 작은 도움말 단추를 누르면 보인다. 키보드 초점과 스크린리더(`aria-describedby` 등)로도 읽혀야 한다. 문구는 `lib/collection-status.ts`의 정의, 카드 표기와 같은 말을 쓴다.
3. 숙소 카드와 상세에서 원어(일본어) 이름과 영어 이름 옆에 한 번 누르면 복사되는 단추를 둔다. 복사되면 짧게 ‘복사됨’을 알린다. 클립보드를 쓸 수 없는 브라우저에서는 이름을 선택해 둔다.
4. 이름 표시 순서가 한국어 → 영어 → 원어인지 확인한다. 다르면 고친다. 자료를 늘리는 일은 D07이 맡는다.
5. 숙소 설명을 그 자리에서 번역해 보이는 아이콘(사용자 원문 5). 새 창으로 번역 사이트를 여는 링크는 쓰지 않는다. 결제가 필요한 방식(Google Cloud Translation API 등)은 쓰지 않는다. LLM 번역도 쓰지 않는다(`roadmap.md` 결정 기록). 결제 없이 되는 방식을 먼저 조사하고, 공식 문서로 지원 범위를 확인한다. 후보는 브라우저에 들어 있는 기기 안 번역 기능(예: Chrome의 Translator API)과 브라우저에서 도는 공개 번역 모델이다. 휴대폰·일부 브라우저에서 안 되면 아이콘을 숨기거나 ‘이 브라우저에서는 번역을 쓸 수 없음’을 보인다. 원문은 늘 함께 보이게 한다. 결제 없이 안정적으로 되는 방식이 없으면 이 항목은 하지 않고, 이유를 PR과 이 문서에 적어 상위 세션을 거쳐 사용자에게 알린다.
6. 지도 위 바다에 숙소 묶음·평점·‘숙소’ 표지만 떠 보이는 현상(사용자 원문 4). 먼저 원인을 찾는다. 후보는 세 가지다. (가) 대략 위치(점선 표지, D06 지오코딩 등급이 낮은 점)의 대표 좌표가 해안·섬 근처 바다에 떨어진 경우. (나) 묶음 표지의 위치를 평균으로 잡아 바다로 간 경우. (다) 좌표 자체가 틀린 숙소. 공개 스냅숏 `geo.json`의 등급별 점으로 바다에 놓인 점의 수와 종류를 센다(`D06-20261013.md` 9절의 등급과 오차). 원인에 맞게 고친다. 예: 묶음 표지를 실제 숙소 점 위에 두기, 대략 위치 점을 지도에 찍지 않고 목록에만 두기, 틀린 좌표는 다음 스냅숏에서 빼기. 숙소가 지도와 목록에서 빠지지 않아야 한다(U05 결정 ‘숙소 빠짐 없음’).

### 1. 필터 체크 표시 때 글자가 밀려 잘림(할 것 1)

운영 화면(2026-10-18T01:1xZ, 공개 GET)에서 쟀다. 1280px 패널의 탕 조건 버튼은 폭 100px이다. 누르면 이름 앞에 ‘✓ ’가 붙어 이름 글자가 오른쪽으로 17px 밀린다(`.filter-chip[aria-pressed=true]>span::before`). 그래서 ‘천연온천 65’, ‘카케나가시 5’, ‘니고리유 10’처럼 숫자가 잘렸다. 누르기 전에도 ‘카케나가시 577’은 3px 넘쳤다. 이름과 숫자와 체크 표시가 한 줄에 들어갈 폭이 없었다.

고친 방법: 체크 표시 자리(14px)를 처음부터 이름 앞에 둔다. 누르기 전에는 빈 네모, 누르면 ✓다. 탕 조건 버튼은 숫자를 이름 아래 줄에 둔다. 그래서 누르기 전후에 이름 글자 위치·줄 수·숫자 줄·버튼 크기가 같고, 숫자가 다섯 자리(전국 23,032곳이 최대)여도 잘리지 않는다. ‘내 기준’은 넓은 버튼이라 한 줄 그대로다. 상태는 색과 함께 빈 네모·✓ 모양으로도 구분된다.

### 2. 옵션별 도움말(할 것 2)

옵션 15개(빠른 조건 7개, 묶음 안 스위치 8개)마다 한두 문장 도움말을 둔다. 문구는 수집 규칙(`scripts/crawler/collect.py`, `lib/hotel-bath-facts.ts`)과 `lib/collection-status.ts`의 말(자란넷, 확인된, 객실 타입)로 썼다. 평점 선택 상자 세 개는 묶음의 ‘?’ 설명이 그대로 맡는다.

- 마우스(`hover:hover`): 옵션에 올리면 0.3초 뒤 툴팁이 뜬다. 툴팁은 패널 오른쪽 바깥에 뜬다. 옵션 바로 아래나 옆에 띄우면 다음 옵션을 가려 누를 수 없어서다. 이미 의존성에 있는 Radix Tooltip(`components/ui/tooltip.tsx`)을 쓴다. 키보드 초점으로도 뜨고 Escape로 닫힌다.

### 3. 이름 순서와 복사 단추(할 것 3·4)

이름 순서 확인 결과: 고치기 전에는 카드·상세 모두 `names.ko`를 제목으로, `names.ja`를 둘째 줄로 썼다. 영어 이름은 상세 아래쪽 ‘다른 이름’에만 있었다. 한국어 이름이 없는 숙소의 `names.ko`에는 수집기가 원어 이름을 넣는다(`collect.py` `localized_names`). 그래서 제목의 순서 규칙이 따로 있지 않았다.

공개 스냅숏(2026-10-17T23:50Z, 23,032곳)의 이름 모양을 셌다(카드 스냅숏 `cards.json`을 받아 `displayNames`로 계산). 세 칸이 같은 이름이 21,528곳(일본어 19,431, 로마자 2,087, 한국어 10)이고, 한국어 이름과 다른 원어 이름이 함께 있는 곳이 1,500곳, 한국어 없이 영어와 원어가 다른 곳이 4곳이다. 새 규칙으로 상세에 영어 줄이 생기는 곳은 1,242곳, 원어 줄이 있는 곳은 1,504곳이다.

- 상세: 한국어 → 영어 → 원어 순서로 세 줄까지 보인다. 영어·원어 이름마다 복사 단추가 있다. ‘다른 이름’은 위에 보인 이름을 빼고 남은 것만 적는다.
- 복사 단추: 누르는 영역 44px, 누르면 클립보드에 이름을 넣고 2초 동안 ‘복사됨’을 보인다(`role=status`로 읽힘). 클립보드를 쓸 수 없으면 이름 글자를 선택해 두고 ‘이름을 선택했어요’를 보인다.
