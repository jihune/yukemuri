## U02 1차 결과

상세는 `U02-20261010.md`, 브라우저 근거는 `evidence/u02-browser-20261010.json`이다.

- 원인: 시설·평점·리뷰 조건의 SQL이 미확인(`NULL`, 확인 비트 0)과 확인된 불일치를 똑같이 제외했다. 지도는 불러온 쪽의 숙소 중 좌표가 있는 숙소만 그렸다. 체크인된 1,655개 중 좌표가 있는 기록은 57개다.
- API 응답에 `unknownExcluded`를 더했다. 선택한 조건을 하나도 어기지 않았지만 하나 이상이 미확인이라 빠진 숙소 수다. 미확인 숙소를 결과에 넣거나 정보를 추정하지 않는다.

- Worker 검사: `check-catalog-worker.mjs`에 대조 숙소 7개 단언을 더했다. 계산의 네 부분을 하나씩 되돌린 대조에서 모두 실패했다.
- 브라우저 검사: 새 `scripts/check-u02-browser.mjs`가 360/390px에서 30개 통과했다(`87372d6`). 앱 파일을 `f43c8bf`로 되돌린 대조에서는 16개 중 10개 실패 후 중단됐다. U01 브라우저 검사 64개도 통과했다.

## 미확인 사항

- 운영 D1 자료로 화면과 쿼리 시간을 확인하지 않았다.
- 실제 모바일 기기, 주소창·안전 영역, 스크린리더, 외부 지도 타일, 1280px 넓은 화면은 확인하지 않았다.

## 이번 세션의 결정

1. 하네스(`jihune/agent-harness`의 `claude/START.md`)를 읽기용으로 붙여 적용했다. 전역 규칙 155줄, 스킬 37개다. 하네스는 수정하지 않았다.
2. 하네스와 유케무리 지침이 충돌한 곳은 유케무리 지침과 사용자 요청을 따랐다.
   - `START.md` 4단계는 적용 뒤 사용자의 다음 메시지를 기다리라고 한다. 사용자 요청이 같은 메시지에서 다음 단계를 지시했으므로 기다리지 않았다.
   - 하네스는 `STATE.md`·요청 원장 기록을 요구한다. `AGENTS.md`의 ‘기록’은 별도 기록 폴더를 금지한다. 이 인수인계와 `roadmap.md`에 기록했다.
   - 하네스는 push를 요청이 있을 때만 하라고 한다. 사용자가 커밋·push·PR을 요청했다.
   - Windows 경로·PowerShell·winget 지침은 Linux 클라우드라 적용하지 않았다.
3. 첫 PR 범위: 미확인 제외 수와 지도 표시 차이 안내, 지도 범위 검색 설계 문서. 지도 범위 검색 구현은 설계 확정 뒤 별도 작업으로 나눴다.
4. 지도의 위치 미확인 수는 불러온 숙소 기준으로 센다. 결과 전체의 좌표 없음 수는 모든 기록의 `payload`를 읽어야 해서 운영 쿼리 시간을 재지 않고 넣지 않았다. 지도 범위 검색 설계에서 다룬다.
