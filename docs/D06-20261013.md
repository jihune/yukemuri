접근 날짜: 아래 공식 문서와 API 응답은 모두 2026-10-13 05:35Z–06:00Z(UTC)에 읽었다. 문서마다 적힌 갱신일은 본문에 따로 적었다.

## 1. 요약

- **좌표는 외부 API 없이 해결할 수 있다.** 좌표가 없는 숙소 11,843곳 중 Jalan 11,006곳은 일본어 주소(원문에 우편번호 포함)를 이미 갖고 있다. 오프라인 지오코더 jageocoder(MIT)와 무료 공개 사전(街区 수준, 351MB)으로 주소 11,885개를 17초에 변환했다. GitHub Actions에서 외부 API 없이 돌릴 수 있다.
- **정확도**(이미 좌표가 있는 Jalan 879곳과 비교):
  - 街区 수준으로 맞은 주소: 오차 중앙값 65m, 90%가 493m 안.
  - 대자(大字) 수준까지만 맞은 주소(농촌·온천지의 지번 주소): 중앙값 약 1km, 90%가 3.7km 안.
- **커버리지:** 지도에 점을 찍을 수 있는 숙소가 10.4% → 93.7%(1단계) → 95.8%(2단계) → 100%(3단계, 마지막 4.2%는 도시 단위 대략 위치)로 늘어난다. 대략 위치는 `isApproximate`와 정밀도 등급으로 구분해 표시한다.
- **Google은 좌표·한국어 이름 용도로 쓰지 않는다.**
  - 약관이 Places·Geocoding 결과를 Google 이외의 지도(Leaflet+OSM)에 쓰는 것을 금지한다.
  - 위경도는 30일까지만 캐시할 수 있고, 업체 이름은 저장할 수 없다.
  - 무료 한도가 월 1만 건 단위라, 매달 1.2만 곳을 갱신하면 넘는다.
- **Rakuten Travel API도 저장 용도로는 쓰지 않는다.** 위경도와 온천 정보는 주지만 약관상 세 가지가 걸린다. ‘불특정 다수가 공유할 수 있는 곳에 저장’ 금지, ‘경쟁 서비스’ 금지, Rakuten 이외 사이트로의 링크 제한이다. 공개 레포·공개 스냅숏 구조와 맞지 않고, 한국어 이름도 없다.
- **한국어 이름은 빠른 해결책이 없다.**
  - 현재 706곳(5.3%)이다. Wikidata의 Trip.com ID 정확 일치로 45곳을 바로 더할 수 있다(CC0).
  - 크게 늘리려면 두 가지가 필요하다. 하나는 kr.trip.com 상세 수집을 이어 가는 것, 다른 하나는 Trip의 원어명·우편번호·좌표로 Jalan 기록과 연결해 한국어 이름을 옮기는 것이다. 이 방법으로 얼마나 늘지는 확인하지 못했다.

## 4. 선택지별 근거

### 4.1 Google Maps Platform

공식 문서는 모두 ‘Last updated 2026-10-08 UTC’다: [가격표](https://developers.google.com/maps/billing-and-pricing/pricing), [과금 개요](https://developers.google.com/maps/billing-and-pricing/overview), [시작하기](https://developers.google.com/maps/get-started), [Places 데이터 필드](https://developers.google.com/maps/documentation/places/web-service/data-fields), [Places 정책](https://developers.google.com/maps/documentation/places/web-service/policies). 약관은 [Terms of Service](https://cloud.google.com/maps-platform/terms)(2026-08-26)와 [Service Specific Terms](https://cloud.google.com/maps-platform/terms/maps-service-terms)(2026-06-10)를 봤다.

가격과 결제 계정:
- 2025-03-01부터 월 $200 크레딧 대신 SKU별 월 무료 한도를 준다.
- 결제 계정이 연결된 Cloud 프로젝트가 필수다(카드 등록).

이 프로젝트에 직접 걸리는 약관 조항:
- 3.2.3(e) No Use With Non-Google Maps. 서비스 약관 14.2·6.2도 Places·Geocoding 콘텐츠를 Google 이외 지도와 함께 쓰는 것을 금지한다.
- 14.3·6.3.1: 위경도는 최대 30일 임시 캐시만 허용한다.
- 3.2.3(a)(iii): 업체 이름·주소·리뷰를 복사해 저장하지 않는다. place_id만 무기한 저장할 수 있다.
- 3.2.3(d)(iii): ‘listings or directory service’ 사용 금지. 숙소 탐색 사이트에 해당하는지는 해석이 필요하다.

### 4.2 Rakuten Travel API

출처는 [施設検索API 2026-07-31판](https://webservice.rakuten.co.jp/documentation/simple-hotel-search)과 [이용 규약](https://webservice.rakuten.co.jp/guide/rule)이다.

제공하는 것:
- `latitude`·`longitude`, `postalCode`, `hotelKanaName`, 욕장 항목(`aboutBath`·`bathQuality`, `squeezeCondition=onsen`).
- `applicationId`와 새 `accessKey`가 필요하다.

약관상 걸리는 조항:
- 제8조 4항: API를 쓴 부분에 Rakuten 이외 링크를 둘 수 없다.
- 제10조 1항 (6): 경쟁 서비스 금지.
- 제10조 1항 (9): 불특정 다수가 공유할 수 있는 곳에 저장 금지.
- 제13조: 크레딧 표시 필수.

공개 스냅숏과 Jalan·Trip 링크 구조와 충돌한다. 새 계정 연결은 사용자 요청 사항이다(`AGENTS.md`).

- 지번 사전(공개 데모 서버, 대자 수준 표본 12곳): 9곳이 지번·街区 수준으로 올라가 오차가 88–1,769m에서 5–213m로 줄었다. 표본이 작아 전국 개선율은 확인하지 못했다.
- 겹침: 지오코딩한 11,006곳이 8,423개 지점에 모인다. 3,699곳이 다른 숙소와 같은 점을 쓰고, 한 점에 최대 49곳이 겹친다. 지도는 같은 점의 숙소를 목록으로 펼쳐야 한다.
- 디지털청 ABR([정책 페이지](https://www.digital.go.jp/policies/base_registry_address)) 데이터 서버는 이 환경(미국 출구)에서 CloudFront 국가 차단 403을 냈다. GitHub Actions도 미국에서 돌므로 막힐 가능성이 크다.

### 4.5–4.7 Nominatim·OSM·Wikidata

- **Nominatim** [사용 정책](https://operations.osmfoundation.org/policies/nominatim/): 최대 초당 1회, 정기 스크립트는 분당 4회, 대량 지오코딩 비권장, 체계적 조회 금지. 쓰지 않는다.
- **OSM**: 일본 `tourism=hotel` 14,981개(Geofabrik taginfo, 2026-10-12)다. 유후인 범위 숙박 POI는 26개, `name:ko`는 0개였다. ODbL 파생 DB 공개 의무가 생길 수 있어 쓰지 않는다.
- **Wikidata**: `Trip.com hotel ID(P10425)` 일본 1,902개 중 247개가 우리 Trip 기록과 정확히 일치한다.
  - 247개 모두 좌표가 있고, 그중 158곳은 우리 쪽에 좌표가 없다.
  - 한국어 레이블은 45곳이 새로 생긴다.
  - CC0이다.

## 7. Google을 쓸지

**좌표와 한국어 이름에는 Google을 쓰지 않는다.**
1. 지도가 Leaflet+OSM이라, Places·Geocoding 결과를 찍으면 약관 위반이다.
2. 위경도는 30일까지만 캐시할 수 있고, 매달 다시 받으면 무료 한도(월 1만)를 넘는다.
3. 한국어 이름은 저장·색인할 수 없어 검색에 쓸 수 없다.
4. 지도를 Google 지도로 바꾸면 무료 로드 한도와 Cloudflare 무료 구조를 보장할 수 없다.

$0으로 약관을 지키며 쓸 수 있는 범위:
- 키 없는 Maps URLs 링크(상세의 ‘주소로 위치 확인’)는 계속 쓴다.
- 이미 만든 요청 시 조회 경로(`lib/google-places.ts`, 기본 꺼짐)는 사용자 결정(로드맵 ‘Google Maps 평점·사진’) 전까지 꺼 둔다. 켤 경우 결제 계정(카드) 위험과 하루 상한(30 이하)을 함께 정한다.

## 8. 확인하지 못한 것

- Google:
  - 실제 응답(키 없음)과 한국어 이름 보유율.
  - ‘listings or directory service’ 조항의 해석.
  - 무료 체험 계정에서의 한도.
- Rakuten: 공식 FAQ의 속도 제한(403), 료칸 수록 수, 제10조 (9)의 정확한 해석.
- 국토지리원 주소 검색 API의 전용 약관.
- ABR 데이터 서버의 국가 차단 범위(한국·Actions에서 열리는지).
- 지번 사전 전체 실행(개선 효과는 표본 12곳만), 정확도 기준(Jalan `staticmap` 중심) 자체의 오차.
- 일본 전체 `name:ko` 수(Overpass 과부하), `kr.trip.com` 목록의 한국어 이름, Jalan 목록 `lookMap()` 데이터 경로.
- Trip 상세 좌표가 어느 필드에서 오는지, Jalan·Trip 공통 숙소 수.
- GitHub Actions에서의 jageocoder 실제 실행. 이 클라우드 환경에서만 실행했고, 문서상 사양(SSD 14GB, 캐시 10GB)으로는 街区 사전에 충분하다.
